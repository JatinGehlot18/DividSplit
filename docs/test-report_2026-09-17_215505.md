## 🐛 Bugs

1. **Logout hangs when backend unreachable — FIXED ✅** (`src/screens/AccountScreen.tsx:78`). It awaited the server logout *before* clearing local state; with no fetch timeout and an unreachable backend, logout silently did nothing and the stale session persisted. Now signs out locally + navigates first; server cleanup is fire-and-forget.

2. **"You're owed, overall" label never flips sign** (`src/screens/GroupDetailScreen.tsx:60`). Hardcoded, even for negative balances — Alice's Goa group showed `-₹1,225` under "You're owed". Should show "You owe" (coral) when the balance is negative.

3. **Stale data after recording a settlement** (`src/util/useApi.ts:44` fetches on mount only; no `useFocusEffect` anywhere). After Settle Up → OK, the reopened GroupDetail still showed the old `-₹1,225` while the API already had 0.
